# Testing

## What is needed to launch the project

- Git - [Download & Install Git](https://git-scm.com/downloads).
- Node.js - [Download & Install Node.js](https://nodejs.org/en/download/) (version 22.14.0) and the npm package manager.

## Test run 

```bash
  npm run test
  npm run coverage
```

## Report run

```bash
  npm run report
  npm run report:win
```
